# 📌 Registration Form with Real-Time Validation

## 📖 Project Description

This project is a simple **Registration Form** built using **HTML, Tailwind CSS, and JavaScript**.
It performs **real-time validation** to ensure that user inputs are correct before allowing form submission.

---

## 🚀 Features

* ✅ Name field validation (cannot be empty)
* ✅ Email validation (must follow correct format)
* ✅ Password validation (minimum 6 characters)
* ✅ Real-time validation using JavaScript
* ✅ Submit button disabled until all fields are valid
* ✅ Clean and responsive UI using Tailwind CSS

---

## 🛠️ Technologies Used

* HTML5
* CSS 
* JavaScript (Vanilla JS)

---

## 📂 Project Structure

```
project-folder/
│
├── index.html      # Main HTML file
└── script.js       # JavaScript validation logic
```


## 🧠 Validation Rules

* **Name**: Must not be empty
* **Email**: Must be a valid email format (e.g., [example@mail.com](mailto:example@mail.com))
* **Password**: Must contain at least 6 characters

---

## 📸 Output

* Form prevents submission until all inputs are valid
* Error messages are shown below each field
* Submit button becomes active only when all validations pass

  
## 🙌 Conclusion

This project helps beginners understand **form validation, DOM manipulation, and UI styling using Tailwind CSS**.
